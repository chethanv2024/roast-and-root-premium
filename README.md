# ROAST & ROOT — Premium Coffee Storefront

A responsive React + Vite coffee storefront with a warm editorial design, animated page transitions, floating 3D coffee beans, product filtering, product detail pages, persistent cart, journal, story, contact form demo, and newsletter interaction.

## Requirements
- Node.js 18.18+ (Node 20 LTS recommended)
- npm

## Run locally
1. Extract the ZIP.
2. Open the extracted `roast-and-root-premium` folder in VS Code.
3. Open Terminal in that folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed in the terminal (normally `http://localhost:5173/`).

## Production build
```bash
npm run build
npm run preview
```

## Included
- Responsive home, shop, product detail, cart, story, journal, and contact pages
- Framer Motion entrances and route transitions
- React Three Fiber / Three.js 3D floating coffee-bean scene
- Unsplash photography URLs (internet connection required for remote images)
- LocalStorage cart persistence
- Roast filters and price sorting
- Add-to-cart and quantity controls

## Before using for real sales
This is a ready-to-run frontend demo, not a production payment system. Checkout is a placeholder. Connect Shopify, Stripe, Razorpay, or another payment provider and a backend/order service before taking real orders. Replace demo email addresses and connect the contact/newsletter forms to a real service. Product prices and copy are sample content.
